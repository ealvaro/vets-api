# Disability PDF development

The core 526 pdf is generated by request to Lighthouse (LH).  Ancillary forms can be generated locally.

## Setting up PDF Generation

For core 526 pdf generation:

- [Set up your AWS Account](https://depo-platform-documentation.scrollhelp.site/developer-docs/set-up-your-aws-account)
- [Generate a local RSA key and request a token](https://developer.va.gov/explore/api/benefits-claims/client-credentials)
- [Get CCG Sandbox Access](https://developer.va.gov/explore/api/benefits-claims/sandbox-access)

## Configuration

In your `settings.local.yml`, add:

```yaml
lighthouse:
  api_key: YOUR-API-KEY
  auth:
    client_credentials:
      verify_ssl: false
  benefits_claims:
    access_token:
      aud_claim_url: https://deptva-eval.okta.com/oauth2/ausdg7guis2TYDlFe2p7/v1/token
      client_id: YOUR-CLIENT-ID
      rsa_key: PATH-TO-YOUR-RSA.key
    aud_claim_url:
    form526:
      access_token:
        aud_claim_url: https://deptva-eval.okta.com/oauth2/ausdg7guis2TYDlFe2p7/v1/token
        client_id:
        rsa_key:
      host: https://staging-api.va.gov
      use_mocks: false
    # host: https://fwdproxy-staging.vfs.va.gov:4475
    host: https://localhost:4475
    use_mocks: false
    verify_ssl: false
```

Install AWS shell libraries

```shell
brew install awscli
brew install --cask session-manager-plugin
```

## Create a Form 526 Submission

Before generating PDFs, you need to create a `Form526Submission` with test data.

Use the [create_526_claim_submission.rb](./create_526_claim_submission.rb) script:

```shell
bundle exec rails runner lib/disability_compensation/create_526_claim_submission.rb \
  --json-path path/to/form526.json \
  --user-icn 1012860875V895695
```

This creates both a `SavedClaim::DisabilityCompensation::Form526AllClaim` and a `Form526Submission`, and returns:

```json
{
  "saved_claim_id": 18,
  "submission_id": 12,
  "user_uuid": "c2ca32c1-0af0-4a7c-9f4a-85d804894e14",
  "user_icn": "1012860875V895695"
}
```

You can then reference `Form526Submission.last` in the rails console for the subsequent PDF generation steps below.

### Generate 21-526 core PDF

Start a forward proxy tunnel:

```shell
cd path/to/vets-api
script/forward-proxy-tunnel.sh staging 4475 4475
# > enter AWS username
# > enter AWS MFA
# ...
# ...
# Starting port forwarding session to: i-####### from local port 4475 to remote port 4475
#
# Starting session with SessionId: #####
# Port 4475 opened for sessionId #####
# Waiting for connections... # this means the tunnel was successful
```

Enter your local rails console in another terminal:

```ruby
s = Form526Submission.last
p = LighthouseGeneratePdfProvider.new(s.user_account.icn)
r = p.generate_526_pdf(s.form['form526'].to_json, "manual-#{s.id}")

# Save the Lighthouse response body to a local PDF file.
pdf_path = Rails.root.join('tmp', "526-#{s.id}.pdf")
File.binwrite(pdf_path, r.body)

# Optional sanity checks
puts "Saved PDF to #{pdf_path}"
puts "Bytes written: #{File.size(pdf_path)}"
```

If `r.body` is blank or the saved file is 0 bytes, verify the request succeeded and inspect `r.status`/`r.body` for API errors.

### Generate 21-0781 PDFs locally

Use the existing 526 submission and generate any present ancillary mental health PDFs
(21-0781, 21-0781a, and/or 21-0781V2) without uploading them to VBMS.

```ruby
# In rails console
s = Form526Submission.last
job = EVSS::DisabilityCompensationForm::SubmitForm0781.new
docs = job.get_docs(s.id, "manual-#{s.id}")
# Returns an array like:
# [{ type: '21-0781', file: '/tmp/...pdf' }, { type: '21-0781a', file: '/tmp/...pdf' }]
```

If `docs` is empty, the submission does not include `form0781`, `form0781a`, or `form0781v2` content.

### Generate 21-8940 PDF locally

Use the 8940 worker helper to generate the ancillary PDF without uploading it.

```ruby
# In rails console
s = Form526Submission.last
job = EVSS::DisabilityCompensationForm::SubmitForm8940.new
doc = job.get_docs(s.id)

# doc => { type: '21-8940', file: <Form8940Document ...> }
pdf_path = doc[:file].pdf_path
```

If `pdf_path` is nil, the submission likely does not include `form8940.unemployability` content.

### Generate 21-4142 / 21-4142a PDF packet locally

`form4142` data for 526 is processed by the 4142 processor and rendered as one generated PDF packet.

```ruby
# In rails console
s = Form526Submission.last
processor = EVSS::DisabilityCompensationForm::Form4142Processor.new(s, "manual-#{s.id}")
pdf_path = processor.pdf_path
```

If this raises a validation error, confirm the submission has valid `form4142` data.
